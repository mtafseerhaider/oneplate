# Tarbiyah

Source material for the Learn library: the raw texts the daily content is drawn from and checked against.

- `research/` — papers, notes and references (nutrition, fasting, education, Islamic sources).
- `transcripts/` — transcripts of talks, classes and conversations.
- `lectures/` — lecture notes, outlines and slides.

Drop files straight into these folders. Keep the original file name and, where known, add the source and date at the top of the file or in a short note beside it. Material here is reference, not app content: anything that reaches the Learn tab is written into `packages/content` and goes through the review workflow.
